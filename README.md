# Neighbor Noise Check

A phone web app for apartment tours: estimates how much neighbor noise you'll hear through walls and floors.

- **Estimate** – typical STC/IIC ranges from construction, age, knock test and layout.
- **Wall test** – level difference between two sides of a wall with pink noise (ISO 717-1 octave-band rating, corrected for background noise and room echo).
- **Room noise** – A-weighted background meter (L90, Leq, Lmax, noise events).
- **Visits** and **Tips** – compare apartments and a tour checklist.

Open: https://seanwkelley.github.io/neighbor-noise-check/

Single self-contained `index.html`, no build step. Results are approximate; phone microphones are uncalibrated.
